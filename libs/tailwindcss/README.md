# Tailwind CSS (Play CDN)

- **用途**：提供專案使用的 Utility-first CSS 框架。
- **來源版本**：[https://cdn.tailwindcss.com](https://cdn.tailwindcss.com) (最新版 Play CDN)
- **說明**：
  這是一個為瀏覽器環境設計的 Tailwind CSS Play CDN 腳本。它會在瀏覽器端即時編譯 CSS。
  已將其本地化以符合零外部相依 (No CDN) 規範。
  在 HTML 中透過 `<script src="libs/tailwindcss/tailwindcss.js"></script>` 引入使用。
